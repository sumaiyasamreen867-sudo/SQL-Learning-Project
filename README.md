# 📊 SQL Learning Project

## Overview

This repository contains SQL queries completed while following **Luke Barousse's SQL Course**.

The project analyzes a real-world **Data Analyst Job Postings** dataset to answer business questions using SQL.

---

## Project Objectives

- Find the highest-paying remote Data Analyst jobs
- Identify the skills required for those jobs
- Discover the most in-demand Data Analyst skills

##  Key Insights

### Query 1 – Top-Paying Remote Data Analyst Jobs

- The highest-paying remote Data Analyst position offers an annual salary of **$650,000**.
- Leadership roles such as **Director of Analytics** and **Principal Data Analyst** dominate the highest salary range.
- Companies like Meta, AT&T, and SmartAsset offer highly competitive compensation for experienced analytics professionals.

---

### Query 2 – Skills Required for Top-Paying Jobs

- SQL and Python appear consistently across the highest-paying roles.
- Tableau, Power BI, AWS, and Azure are frequently required in senior analytics positions.
- Modern data tools such as Snowflake and Databricks are common in high-paying roles.

---

### Query 3 - Most In-Demand Skills

- SQL is the most requested skill with **92,628** job postings, making it the most essential technical skill for aspiring Data Analysts.
- Traditional business tools such as **Excel** remain highly relevant, ranking second with more than **67,000** job postings.
- Programming and visualization skills—including **Python**, **Tableau**, and **Power BI**—also rank among the top five most requested skills, demonstrating that employers increasingly value analysts who can both process and communicate data effectively.

---

### Query 4 - Highest-Paying Skills

- Specialized technologies such as **SVN**, **Solidity**, **Couchbase**, and **DataRobot** are associated with the highest average salaries in the dataset.
- Many of the top-paying skills relate to **cloud computing**, **machine learning**, and **data engineering**, suggesting that analysts with expertise beyond traditional reporting can access higher-paying opportunities.
- While these skills offer high average salaries, some may appear in relatively few job postings, indicating that demand should be considered alongside salary when choosing which technologies to learn.

---

### Query 5 - Most Optimal Skills to learn

- **Python** stands out as one of the strongest skills to learn because it combines high demand (236 job postings) with an average salary exceeding **$100,000**.
- Visualization tools such as **Tableau** and cloud technologies including **Snowflake**, **Azure**, and **AWS** also provide an attractive balance between demand and salary.
- These findings suggest that combining core analytics skills (**SQL, Python, Tableau**) with modern cloud platforms can significantly improve career opportunities and earning potential.
