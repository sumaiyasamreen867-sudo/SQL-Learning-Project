# 📊 SQL Learning Project

## Overview

This repository contains SQL queries completed while following **Luke Barousse's SQL Course**.

The project analyzes a real-world **Data Analyst Job Postings** dataset to answer business questions using SQL.

---

## Project Objectives

- Find the highest-paying remote Data Analyst jobs
- Identify the skills required for those jobs
- Discover the most in-demand Data Analyst skills
- Analyze which skills command the highest salaries
- Determine the most valuable skills based on demand and salary

---

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINs
- Common Table Expressions (CTEs)
- Window Functions
- Aliases
